01

Alfabeto, palavra e linguagem

Menezes · cap. 2 · p. 54–58
Alfabeto é o conjunto de peças; palavra é uma fila finita delas. ε é o fio sem contas.

Toda a teoria é construída com três peças. Se você entender essas três, o resto do capítulo vira notação.

  • Símbolo (ou caractere): uma entidade abstrata, sem definição formal. Ex.: a, 0, +.
  • Alfabeto Σ: um conjunto finito de símbolos. Ex.: Σ = {a, b}, {0,1}. O conjunto vazio também é um alfabeto.
  • Palavra (cadeia, sentença): uma sequência finita de símbolos do alfabeto, justapostos. Ex.: abba.
  • Palavra vazia ε: a sequência sem nenhum símbolo. Ela existe sobre qualquer alfabeto.
  • Comprimento |w|: o número de símbolos. |abba| = 4, |ε| = 0.
Toda linguagem é um recorte de Σ*. Aqui, L = palíndromos.

Agora pegue todas as palavras possíveis sobre Σ. Isso tem um nome:

  • Σ*: todas as palavras sobre Σ, incluindo ε.
  • Σ⁺: todas as palavras sobre Σ, exceto ε. Ou seja, Σ⁺ = Σ* − {ε}.
Definição · Linguagem formal

Uma linguagem formal L sobre Σ é qualquer subconjunto de Σ*. Só isso. Pode ser finita, infinita ou vazia.

  • ∅ e {ε} são linguagens diferentes: a primeira não tem palavra nenhuma, a segunda tem uma (a vazia).
  • Σ* e Σ⁺ também são linguagens sobre Σ.
  • O conjunto dos palíndromos sobre {a,b} é uma linguagem infinita.
  • Uma linguagem de programação (Pascal, C) é o conjunto de todos os programas válidos. Cada programa é uma palavra.

Prefixo, sufixo e subpalavra

  • Prefixo: qualquer sequência inicial. Prefixos de abb: ε, a, ab, abb.
  • Sufixo: qualquer sequência final. Sufixos de abb: ε, b, bb, abb.
  • Subpalavra: qualquer prefixo de um sufixo (um trecho contínuo). Toda palavra é prefixo, sufixo e subpalavra de si mesma.

Concatenação

A ordem dos vagões importa: ab·ba ≠ ba·ab.
  • Concatenação vw: junta as duas palavras. Se v = ab e w = ba, então vw = abba.
  • É associativa: v(wt) = (vw)t.
  • ε é o elemento neutro: εw = wε = w.
  • Não é comutativa: ab·ba ≠ ba·ab.
  • Concatenação sucessiva wⁿ: w concatenada com ela mesma n vezes. Por definição w⁰ = ε e wⁿ = wⁿ⁻¹w.
  • |vw| = |v| + |w|.
  • Reverso wᴿ: a palavra de trás para frente. Se w = abc, wᴿ = cba. Palíndromo é quando w = wᴿ.

Operações sobre linguagens

Como linguagens são conjuntos, valem as operações de conjunto, mais duas próprias:

  • União, interseção, diferença: L₁ ∪ L₂, L₁ ∩ L₂, L₁ − L₂.
  • Concatenação de linguagens: L₁L₂ = { uv | u ∈ L₁ e v ∈ L₂ }. Ex.: {a, b}·{c} = {ac, bc}.
  • Fecho de Kleene de uma linguagem: L* = L⁰ ∪ L¹ ∪ L² ∪ …, com L⁰ = {ε}. É o mesmo "*" de Σ*, aplicado a L.

Alguns livros escrevem a palavra vazia como λ em vez de ε. É a mesma coisa.

02

Gramáticas: regras que geram palavras

Menezes · cap. 2 · p. 58–63
Uma descrição finita que fabrica infinitas palavras.

Uma linguagem infinita não cabe numa lista. Precisamos de uma descrição finita que produza todas as palavras dela. A gramática faz isso: é um conjunto de regras de substituição.

Definição · Gramática

Uma gramática é uma quádrupla G = (V, T, P, S):

  • V: conjunto finito de variáveis (não-terminais). Aqui em azul: S, N, D, E.
  • T: conjunto finito de terminais, disjunto de V. São os símbolos que aparecem nas palavras finais.
  • P: conjunto finito de regras de produção α → β. Lê-se "α pode ser trocado por β". α tem pelo menos uma variável.
  • S ∈ V: a variável inicial.
Cada ⇒ é um passo. Termina quando não sobra variável (azul).
  • Abreviação: S → aSb | ε significa duas regras, S → aSb e S → ε.
  • Passo de derivação ⇒: aplicar uma regra uma vez. Se α → β está em P, então uαv ⇒ uβv.
  • ⇒* é zero ou mais passos. ⇒⁺ é um ou mais passos.
  • Uma forma sentencial é qualquer coisa que aparece no meio do caminho (mistura de variáveis e terminais).

Definição · Linguagem gerada

A linguagem gerada por G (Menezes escreve GERA(G) ou L(G)) é o conjunto de palavras só de terminais que dá para derivar a partir de S:

L(G) = { w ∈ T* | S ⇒⁺ w }
  • Exemplo do livro, duplo balanceamento: G = ({S}, {a,b}, {S → aSb, S → ε}, S) gera { aⁿbⁿ | n ≥ 0 } = {ε, ab, aabb, aaabbb, …}.
  • Exemplo do livro, números naturais: N → D | DN e D → 0 | 1 | … | 9 geram qualquer sequência de dígitos.
  • Duas gramáticas são equivalentes se geram a mesma linguagem: L(G₁) = L(G₂). As regras podem ser bem diferentes.
  • Ideia chave do capítulo: gramática é um formalismo gerador (produz palavras). Autômato é um formalismo reconhecedor (diz sim/não para uma palavra). Os dois lados vão se encontrar na Hierarquia de Chomsky.
03

O limite das linguagens regulares

Vídeo · LFA Aula 11 · Linguagens não-regulares ↗
em loopO AFD leu vários a, mas só sabe em qual estado está. Contar até n exigiria n estados.

Relembrando: uma linguagem é regular se algum autômato finito (AFD ou AFN) a reconhece, ou, equivalentemente, se uma expressão regular a descreve. O ponto fraco de um autômato finito é a memória: ele só "lembra" em qual estado está, e são finitos.

  • Um AFD com 5 estados consegue distinguir no máximo 5 "situações".
  • Para reconhecer aⁿbⁿ, ele precisaria lembrar quantos a leu. Esse número pode ser 6, 100, 10⁹… Não cabe em uma quantidade fixa de estados.
  • Conclusão intuitiva: linguagens que exigem contar sem limite ou casar pares não são regulares.

Exemplos clássicos de linguagens não-regulares

  • { aⁿbⁿ | n ≥ 0 }: mesma quantidade de a e b.
  • { wwᴿ | w ∈ {a,b}* }: palíndromos de tamanho par.
  • Parênteses balanceados: (()(())).
  • { w | w tem o mesmo número de a e b }.
  • { aᵖ | p é primo }, { ww | w ∈ {a,b}* }.

No vídeo aparece como 0ⁿ1ⁿ; aqui uso a e b, é a mesma linguagem com outros símbolos.

Pegadinha do vídeo

"Tem que contar" precisa ser contagem ilimitada que será comparada depois. A linguagem das cadeias binárias com o mesmo número de ocorrências de 01 e de 10 parece exigir contagem, mas é regular: essas ocorrências se alternam, então basta saber o primeiro e o último símbolo. Um AFD faz isso com poucos estados.

Ler p símbolos visita p+1 estados. Com p estados, algum repete.

Intuição não é prova. A ferramenta para provar é o lema do bombeamento. Ele vem de uma observação simples sobre caminhos dentro de um AFD: se a palavra é maior do que o número de estados, algum estado se repete, e isso cria um laço.

em loopCom 0, 1, 2 ou 3 voltas no laço y, o caminho ainda termina aceitando.
Lema do bombeamento · linguagens regulares

Se L é regular, então existe um número p (o comprimento de bombeamento) tal que toda palavra w ∈ L com |w| ≥ p pode ser dividida em w = xyz com:

  • |y| ≥ 1 (o laço lê pelo menos um símbolo);
  • |xy| ≤ p (a repetição acontece dentro dos p primeiros símbolos);
  • xyⁱz ∈ L para todo i ≥ 0 (dá para repetir o laço quantas vezes quiser, ou pular).

Para que serve

  • O lema diz: regular ⇒ bombeável. Ele não serve para provar que algo é regular.
  • Usamos a contrapositiva: se L não é bombeável, L não é regular.
  • A prova é sempre por contradição: suponha que L é regular, aplique o lema, chegue em um absurdo.

Receita: provar que L não é regular

Ele joga 1 e 3, você joga 2 e 4. Você ganha se vencer toda divisão.

Pense num jogo contra um adversário que defende que L é regular. Você só ganha se vencer qualquer jogada dele.

  • 1. Adversário escolhe p. Você não sabe o valor, trate como genérico.
  • 2. Você escolhe uma palavra w ∈ L com |w| ≥ p. Escolha uma que deixe o adversário sem saída. Para aⁿbⁿ: w = aᵖbᵖ.
  • 3. Adversário divide w = xyz respeitando |y| ≥ 1 e |xy| ≤ p. Você precisa considerar todas as divisões possíveis.
  • 4. Você escolhe um i e mostra que xyⁱz ∉ L.
  • Como funcionou para toda divisão, L não satisfaz o lema. Contradição: L não é regular.

Jogue com aⁿbⁿ. Mexa em p, tente esconder y onde quiser e veja se escapa:

Erros comuns
  • Escolher um p específico (ex.: "seja p = 3"). Quem escolhe p é o adversário.
  • Escolher você mesmo a divisão xyz. Você tem que derrotar todas.
  • Escolher w curta demais ou fora de L.
  • Achar que "passar no lema" prova que L é regular. Existem linguagens não-regulares que passam.

Fechamento do vídeo: se nem aⁿbⁿ cabe num autômato finito, precisamos de um formalismo mais forte. Gramáticas livres do contexto (gerador) e autômatos com pilha (reconhecedor) resolvem exatamente esse tipo de linguagem.

04

Linguagens livres do contexto

Menezes · cap. 6 · p. 153–156
Duplo balanceamento: o último que abriu é o primeiro a fechar.

O Menezes abre o capítulo dizendo que as linguagens livres do contexto (LLC) cobrem um universo maior que o das regulares, e que o exemplo típico é o duplo balanceamento: estruturas que abrem e fecham em pares.

  • Parênteses em expressões aritméticas.
  • Blocos begin … end, { … }, if … then … else.
  • Por isso as LLC são a base de analisadores sintáticos (parsers), compiladores e tradutores.

Dois formalismos descrevem as LLC:

  • Gramática livre do contexto (GLC): formalismo gerador.
  • Autômato com pilha (AP): formalismo reconhecedor. É um autômato finito com uma pilha como memória extra.
Definição · Gramática livre do contexto

Uma gramática G = (V, T, P, S) em que toda regra tem a forma

A → α   onde A ∈ V e α ∈ (V ∪ T)*

Do lado esquerdo vai exatamente uma variável, sozinha. Do lado direito vai qualquer coisa, inclusive ε.

Linguagem livre do contexto = linguagem gerada por alguma GLC.

Por que "livre do contexto"?

Em cima, A troca em qualquer lugar. Embaixo, só entre a e b.
  • Como o lado esquerdo é só A, a variável pode ser substituída não importa o que está em volta dela.
  • Compare com uma regra sensível ao contexto como aAb → aab: ali A só vira a quando está entre a e b.
  • Toda gramática regular é livre do contexto. A recíproca é falsa: S → aSb é GLC e não é regular.

Exemplos do livro

  • Duplo balanceamento: S → aSb | ε gera { aⁿbⁿ | n ≥ 0 }. O a e o b que entram juntos ficam "casados" pela mesma regra. É assim que a GLC faz o que o AFD não consegue.
  • Expressões aritméticas: E → E+E | E*E | (E) | x gera x, x*(x+x), ((x))…

BNF: a mesma coisa com outra roupa

Mesma gramática: só muda a notação.

A Backus-Naur Form é a notação usada para especificar linguagens de programação (começou com o ALGOL). Ela é uma GLC escrita assim:

  • variáveis entre ⟨ ⟩, com nomes legíveis;
  • ::= no lugar de →.
⟨expr⟩ ::= ⟨expr⟩ + ⟨expr⟩ | ⟨expr⟩ * ⟨expr⟩ | ( ⟨expr⟩ ) | x

Árvore de derivação

  • A raiz é a variável inicial. Cada nó interno é uma variável; seus filhos são o lado direito da regra aplicada.
  • As folhas, lidas da esquerda para a direita, formam a palavra.
  • A árvore ignora a ordem em que as regras foram aplicadas e mostra só a estrutura. Por isso, para GLC ela é a representação natural de uma derivação.
  • Se uma mesma palavra tem duas árvores diferentes, a gramática é ambígua. Compare os dois botões "x+x*x" abaixo.
05

Autômatos com pilha

Vídeo · Autômatos com pilha ↗
em loopCada a empilha um A; cada b tira um. Sobrou só o $: mesma quantidade.

Um autômato com pilha (AP, ou PDA em inglês) é um autômato finito não determinístico + uma pilha. A pilha é memória ilimitada, mas com acesso restrito: só dá para mexer no topo.

  • Empilhar (push): coloca um símbolo no topo.
  • Desempilhar (pop): tira o símbolo do topo.
  • Último a entrar é o primeiro a sair (LIFO). Isso combina com balanceamento: o último ( aberto é o primeiro a ser fechado.
Definição formal (notação do vídeo)

Um AP é uma 6-upla M = (Q, Σ, Γ, δ, q₀, F):

  • Q: estados (finito). q₀: estado inicial. F ⊆ Q: estados de aceitação.
  • Σ: alfabeto de entrada.
  • Γ: alfabeto da pilha. Pode ter símbolos que não estão em Σ, como $ ou A.
  • δ: Q × Σ_ε × Γ_ε → 𝒫(Q × Γ_ε): a função de transição. Recebe estado, símbolo lido (ou ε) e topo da pilha (ou ε), e devolve um conjunto de opções (por isso é não determinístico).

Lendo uma transição a, b → c

Qualquer um dos três pode ser ε (não faz nada).

Na seta entre dois estados aparece a, b → c: "lê a da entrada, troca b do topo da pilha por c". Qualquer um dos três pode ser ε:

RótuloO que fazUso típico
a, ε → Alê a, não tira nada, empilha Acontar / guardar
b, A → εlê b, desempilha A, não empilhacasar / cancelar
ε, ε → $não lê nada, empilha $marcar o fundo da pilha
ε, $ → εnão lê, desempilha $testar "pilha vazia" antes de aceitar
a, ε → εsó lê aignorar símbolos
  • Se o topo não for o símbolo pedido, a transição não pode ser usada naquele ramo.
  • O AP não tem teste "pilha vazia?" embutido. O truque é empilhar $ no começo: ver $ no topo significa "pilha vazia".

Computação: configurações

Uma fotografia completa da máquina num instante.
  • Uma configuração ou descrição instantânea (ID) é uma fotografia da máquina: a tripla (q, w, γ) = (estado, entrada que falta ler, conteúdo da pilha).
  • Convenção do vídeo: a pilha é escrita na horizontal com o topo à direita. $AA quer dizer $ no fundo e A no topo.
  • Um movimento entre IDs se escreve com a catraca: (q2, abb, $A) ⊢ (q3, bb, $). ⊢* é zero ou mais movimentos.
  • Como δ devolve um conjunto, a computação vira uma árvore de ramos. Ramos que travam (nenhuma transição possível) simplesmente morrem.
Dois critérios de aceitação
  • Por estado final: algum ramo consome a entrada toda e para em q ∈ F. O que sobrou na pilha não importa. É o critério usado nas figuras.
  • Por pilha vazia: algum ramo consome a entrada toda e deixa a pilha vazia.
  • Para APs não determinísticos os dois critérios reconhecem as mesmas linguagens.

O AP abaixo reconhece { aⁿbⁿ | n ≥ 0 }. Troque a entrada e acompanhe a pilha:

  • Com aabbb, sobra um b quando a pilha já está no $: não há transição b, $ → …, o ramo morre.
  • Com abab, depois de ir para q3 não existe transição lendo a. Rejeita.
  • q1 é de aceitação para aceitar ε (n = 0).
06

Mais exemplos: projetando APs

Vídeo · APs: mais exemplos ↗
Empilha a 1ª metade; a 2ª sai na ordem inversa e confere.

Projetar um AP é responder: o que eu preciso lembrar, e em que ordem vou conferir? A pilha devolve as coisas ao contrário, então ela é perfeita para conferir algo "espelhado".

Palíndromos pares: { wwᴿ }

  • Empilha cada símbolo da primeira metade.
  • No meio, passa para o estado de conferência.
  • Cada símbolo da segunda metade tem que ser igual ao topo. Desempilha.
  • O problema: como saber onde é o meio? Não sabe. O AP chuta com uma ε-transição. Como ele é não determinístico, existe um ramo que chuta certo, e basta um ramo aceitar.
  • Isso mostra que AP não determinístico é mais forte que o determinístico: wwᴿ não tem AP determinístico.
em loopO AP tenta todos os "meios" ao mesmo tempo. Só o ramo que chuta a posição 2 aceita abba.

{ aⁱbʲcᵏ | i = j ou i = k }

"Ou" vira dois ramos. Basta um aceitar.
  • Empilha os a.
  • Chuta qual igualdade vai testar: ramo de cima confere a com b (e ignora c); ramo de baixo ignora b e confere a com c.
  • "Ou" em linguagem costuma virar dois ramos não determinísticos.

Escolha a máquina. Na contagem final aparece quantas configurações o simulador explorou: são os ramos do não determinismo.

Dicas de projeto
  • Comece empilhando $. Termine com ε, $ → ε indo para o estado final.
  • Use um estado por "fase" da palavra (lendo a, lendo b, lendo c).
  • Precisa contar duas coisas ao mesmo tempo contra uma terceira (aⁿbⁿcⁿ)? Uma pilha não basta. Esse é o sinal de que a linguagem não é livre do contexto.
Teorema central

Uma linguagem é livre do contexto se e somente se algum autômato com pilha a reconhece. GLC (gerador) e AP (reconhecedor) têm exatamente o mesmo poder.

07

Hierarquia de Chomsky

Vídeo · LFA Aula 19 · Hierarquia de Chomsky ↗
Subir de tipo = dar mais memória à máquina.

Noam Chomsky classificou as gramáticas pelo formato das regras. Quanto mais restrita a regra, menor a classe de linguagens. Cada classe tem uma máquina reconhecedora correspondente. É o mapa que amarra toda a disciplina.

TipoClasse de linguagensForma das regrasReconhecedorExemplo
0Recursivamente enumeráveisα → β, sem restrição (α contém variável)Máquina de Turingproblema da parada
1Sensíveis ao contextoα → β com |α| ≤ |β|MT com fita limitada (ALL)aⁿbⁿcⁿ, ww
2Livres do contextoA → αAutômato com pilhaaⁿbⁿ, wwᴿ
3RegularesA → aB ou A → a (linear à direita)Autômato finitoa*b*
  • As inclusões são próprias: Tipo 3 ⊊ Tipo 2 ⊊ Tipo 1 ⊊ Tipo 0. Sempre existe uma linguagem no anel de fora que não está no de dentro.
  • Para separar Tipo 3 de Tipo 2 usamos o lema do bombeamento da seção 3 (aⁿbⁿ). Para separar Tipo 2 de Tipo 1 existe um lema do bombeamento para LLC (aⁿbⁿcⁿ).
  • Ao subir de tipo, a máquina ganha memória: nenhuma (AF) → pilha (AP) → fita do tamanho da entrada (ALL) → fita infinita (MT).
  • Dentro do Tipo 2 há uma subclasse importante: as LLC determinísticas, reconhecidas por AP determinístico. São elas que os parsers de compiladores usam (gramáticas LL(k) e LR(k)). wwᴿ é LLC mas não é determinística.
  • No Tipo 3, gramática regular, expressão regular, AFD, AFN e AFN-ε têm todos o mesmo poder.
  • Fora do Tipo 0 ainda existem linguagens que nenhuma máquina de Turing reconhece.
